# Skills

Guides for anyone, person or agent, working in this repository. Each folder holds one
`SKILL.md` with its job, its rules and the checks that prove the work. Use the smallest set that
covers the task.

| Skill | Use it when |
|---|---|
| [`is-code`](is-code/SKILL.md) | Writing or reviewing Rust: which crate, never crash, errors, tests, style, dependencies. The code guide. |
| [`is-devx`](is-devx/SKILL.md) | Setting up, building, running, checking, coverage, hooks, CI, branches and commits. |
| [`is-content`](is-content/SKILL.md) | Adding or changing subjects, bands, grades, skills or problems in `content/catalog.toml`. |
| [`is-ui`](is-ui/SKILL.md) | Changing the window: screens, theme, fonts, accessibility labels, UI tests, the screen pictures. |
| [`is-clean-room`](is-clean-room/SKILL.md) | Building anything that resembles an existing product, opening a reference product, or using material whose origin is unclear. |
| [`study-wb`](study-wb/SKILL.md) | The JavaScript proof of concept: offline practice pages built from content files. |

Order for a substantial change: `is-clean-room` when it follows a reference product, `is-code`,
then `is-content` or `is-ui` as the change needs, and
`is-devx` for the checks before calling it done.
